# Repor na Hora (nome provisório)

Landing page de validação de um app independente para lojas Nuvemshop. Ele avisa antes de um produto esgotar e sugere quanto repor com base nas vendas.

- Página estática: `index.html` com HTML e CSS num só arquivo, sem framework.
- Formulário: o envio vai para a constante `FORM_ENDPOINT` no fim do `index.html` (FormSubmit ou Formspree).
- Projeto independente, sem vínculo com a Nuvemshop.
